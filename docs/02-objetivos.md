# 2. Objetivos

## Objetivo general

Diseñar e implementar un sistema de automatización capaz de monitorear los niveles de un tanque mediante lógica combinacional, utilizando CODESYS y OpenPLC.

## Objetivos específicos

- Analizar las combinaciones generadas por las entradas B1, B2 y B3.
- Diseñar la lógica de control mediante Ladder Logic.
- Desarrollar una HMI en CODESYS para visualizar el comportamiento del tanque.
- Implementar la misma lógica en OpenPLC.
- Validar el funcionamiento mediante un prototipo físico.
- Detectar combinaciones incoherentes de sensores mediante la señal H5.
- Documentar el proceso de diseño, implementación y pruebas.

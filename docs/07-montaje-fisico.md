# 7. Montaje físico

El prototipo físico utilizará:

- 1 Arduino UNO.
- 1 protoboard.
- 3 switches para B1, B2 y B3.
- 2 pulsadores para START y STOP.
- 5 LEDs para H1-H5.
- 5 resistencias de 220 ohmios.
- Cables jumper.
- Cable USB para programación y alimentación del Arduino.
